# SEA Energía

Sitio one-page para SEA Energía, empresa de Sierra de los Padres dedicada a:

- Diseño, dimensionamiento e instalación de sistemas solares llave en mano.
- Proyectos, montajes y mantenimiento de electricidad industrial.

## Vista local

```bash
npm run dev
```

El sitio es estático: `index.html`, `assets/css/99-template.css` y `js/main.js`.

Las fotografías actuales provienen del template y se pueden reemplazar más adelante. Antes de publicar, hay que conectar los datos reales de WhatsApp/correo en el bloque de contacto.

> No ejecutar `npm run build:clone`: ese comando reconstruye el clon original y sobrescribe la personalización.
